# 🎲 Simulación Montecarlo - Yatzhee

## 📌 Descripción
Este proyecto implementa una simulación del juego Yatzhee para dos jugadores utilizando el método de Montecarlo.

El objetivo es analizar el comportamiento del sistema a través de múltiples ejecuciones, utilizando variables aleatorias con distribución uniforme.

---

## ⚙️ Características
- Simulación de lanzamiento de dados (1 a 6)
- Sistema de puntuación simplificado
- Simulación de múltiples partidas
- Análisis estadístico (media y varianza)
- Visualización de resultados con gráficas
- Interfaz interactiva en Google Colab

---

## 🧠 Fundamento teórico

El modelo se basa en:

- Método de Montecarlo
- Distribución uniforme discreta
- Modelo estocástico
- Cadena de Markov (memoria sin historia)
